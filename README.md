## Консольное приложение: Рандомайзер студентов

Приложение хранит список студентов и их номер группы, позволяет добавлять/удалять студентов, сохраняет данные в JSON и умеет случайно выбирать студента из всего списка или конкретной группы.

### Установка и запуск

Требуется Python 3.9+.

```bash
python3 /workspace/app.py
```

Данные автоматически сохраняются в файл `students.json` рядом со скриптом.

### Возможности
- Добавить студента с номером группы
- Удалить студента
- Показать всех студентов
- Показать группы и количество студентов в них
- Случайно выбрать студента из всех
- Случайно выбрать студента из выбранной группы
- Импорт/экспорт JSON

### Формат данных

Файл `students.json` содержит список объектов:

```json
[
  {"name": "Иван Иванов", "group": "101"},
  {"name": "Петр Петров", "group": "102"}
]
```
